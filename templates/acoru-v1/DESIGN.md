# デザイン仕様 v1.0.0

## 共通デザイン

| 項目 | 仕様 |
|---|---|
| 用紙 | A4縦、595.5 × 842.25 pt |
| 本文左右端 | x=52 / 543.5 pt |
| ブランド色 | 紫 #534491 |
| 本文・社名 | RGB (0.22, 0.22, 0.26)、約 #383842 |
| 補助文字 | RGB (0.43, 0.43, 0.49)、約 #6E6E7D |
| 淡色背景 | RGB (0.965, 0.957, 0.983)、約 #F6F4FB |
| 罫線 | RGB (0.84, 0.83, 0.88)、約 #D6D4E0 |
| フォント | Noto Sans JP Regular。PDFに埋め込む |
| タイトル | 中央、25 pt。下に英文種別8 pt |
| 発行日 | 右上。右端543.5 / ベースライン714 pt、9 pt |
| 宛名 | 左上、13 pt。敬称と下線 |
| 社名 | 右上、18 ptを基準に幅へ調整。本文と同じ黒系 |
| 明細 | 項目・数量・金額（税抜）の3列。本文10 pt |
| 金額集計 | 右下。小計、消費税10%、合計税込 |
| ロゴ | 最下部の横長枠の右側。48.2 × 62 pt |

上下の紫色帯、見出しの色、金額欄の淡色背景、余白を共通化します。通常7行の明細枠を確保し、明細や条件が長い場合は折り返し・改ページします。帳票番号、顧客住所、登録番号、補足事項欄は表示しません。請求元の住所・電話番号は表示します。

## 種類による違い

| 項目 | 請求書 | 見積書 |
|---|---|---|
| タイトル | 請 求 書 / INVOICE | 見 積 書 / QUOTATION |
| 宛名ラベル | ご請求先 | お見積先 |
| 合計のラベル | ご請求金額 | お見積金額 |
| 期限 | お支払期日 | 見積有効期限 |
| 最下部 | お振込先 | お見積条件（納期・条件） |
| 条件未入力時 | - | お問い合わせ案内 |

見積書に振込先・支払期日・請求の文言は表示しません。請求書の補足事項欄を復活させず、見積条件は見積書だけに表示します。

## 検証基準

1. 架空顧客の請求書・見積書をそれぞれ生成し、PNGへレンダリングして全ページを目視確認する。
2. 宛名・日付・明細・合計の文字が重ならず、削除指定の項目が出ないこと。
3. 金額は数量×単価、小計の10%切り捨て、税込合計が一致すること。
4. 多数明細・長い条件でも明細と最下部の枠が重ならないこと。
5. 実際の顧客宛先を使用した送信を検証に含めないこと。

バージョンはPDFのメタデータに記録し、帳票の表示面へ管理用情報を増やしません。
