# PDF font

Noto Sans JP Regular, distributed under the SIL Open Font License.
Source: https://github.com/google/fonts/blob/main/ofl/notosansjp/NotoSansJP%5Bwght%5D.ttf

The bundled static TrueType instance is generated with fontTools 4.66.0 using `instantiateVariableFont(font, {'wght': 400})`. The PDF embeds the font without fontkit subsetting to avoid missing glyphs. Keep this static TrueType instance and verify rendered pages when changing fonts.
