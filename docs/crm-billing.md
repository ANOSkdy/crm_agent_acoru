# CRMと請求の連携

会社名・住所はCRMの `companies`、請求担当者は `contacts`、参考金額は `deals` を参照する。請求設定は `billing.customers.company_id` で会社に一意に紐付ける。会社詳細から請求の有効／無効と請求履歴を開ける。請求側で別の顧客を追加する必要はない。

月次請求の内容を確認済みにして有効化すると、当月分を「送信待ち」で作成する。未確認の場合は「仮作成」（保留）となる。後から確認済みにして保存した場合、当月の未編集（version=1）かつ未送信の仮請求書だけを確認済みの内容で送信待ちに更新する。個別編集・明示的な保留・過去月・移行データ・送信履歴のある請求書は変更しない。担当者が複数なら選択し、案件の金額が月額であるかを確認する。金額の不明な会社は0円の仮明細で停止する。案件からの仮入力は明示ボタンで行う。月次テンプレートが未確認の場合、定期作成も保留になる。

請求書を個別に確認して「送信待ち」に保存しても仮作成を解除できる。上記の未編集の仮請求書を除き、顧客設定の更新で作成済み請求書を上書きしない。送付先・金額・件名・住所は請求作成時のスナップショット。初回作成・月次自動作成ともに、請求設定の「送付先メールアドレス」を使用する。請求担当者は窓口としての関連付けであり、担当者の選択・メール変更で送付先を上書きしない。作成済み請求書の宛先は各請求書で確認・編集し、送信済みの宛先と送信履歴は変更しない。

無効化は以後の月次作成・既存請求の送信を停止する。請求履歴と送信済みPDFを削除しない。同じ顧客・対象月の請求は再有効化しても二重作成しない。既にメール送信処理が開始したものの取り消しは行わない。

移行では、会社名が一意に完全一致する旧請求顧客だけを関連付ける。曖昧なものは未連携で残す。過去請求の宛名・金額は変更しない。

メール添付・請求書PDFの保存・テンプレート画面で生成する請求書のファイル名は `YYYYMMDD_請求書（顧客名）.pdf`。日付は請求書の発行日、顧客名は請求書に保存された宛名を使い、括弧は全角とする。ファイル名に使えない記号と制御文字は `_` に置き換え、ブラウザへの返却には日本語に対応したファイル名ヘッダーを使用する。

PDFは指定された見積書の紫色の上下帯、中央タイトル、3列明細を引き継いだ請求書。発行日は右上に配置し、請求番号・顧客住所・補足事項は表示しない。請求書では請求元の電話番号の直下にインボイス登録番号だけを表示し、「登録番号」などのラベルは付けない。見積書では登録番号を表示しない。補足事項の編集欄も設けない。金額集計は右下、振込先とロゴは最下部の横長枠にまとめている。支払期日・請求元の会社名・住所・電話番号も記載する。原本PDF全体は配布せず、ロゴだけを画像化して使用する。長い明細や振込先は重ならないようにページ分割する。

請求書・見積書の両方で、請求元名を14pt、宛名を標準19pt、件名を18ptとし、すべて通常の太さで表示する。宛名は敬称まで含めて1行にし、幅268ptに収まらない場合だけ文字サイズを下げる。改行・タブは空白に置換し、9ptでも収まらない宛名は短縮を案内する。件名は18ptのまま折り返し、2行の領域に収まらない場合は短縮を案内する。テンプレート版は1.1.1。変更は新しく生成するPDFに反映され、保存済みの送信原本やダウンロード済みファイルは置き換えない。
