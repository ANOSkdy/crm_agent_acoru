# CRMと請求の連携

会社名・住所はCRMの `companies`、請求担当者は `contacts`、参考金額は `deals` を参照する。請求設定は `billing.customers.company_id` で会社に一意に紐付ける。会社詳細から請求の有効／無効と請求履歴を開ける。請求側で別の顧客を追加する必要はない。

有効化して保存すると当月分を「仮作成」（保留）で作成する。担当者が複数なら選択し、案件の金額が月額であるかを確認する。金額の不明な会社は0円の仮明細で停止する。案件からの仮入力は明示ボタンで行い、既存の契約明細を自動で上書きしない。月次テンプレートが未確認の場合、定期作成も保留になる。

請求書を確認して「送信待ち」に保存すると仮作成を解除できる。顧客設定の更新で作成済み請求書を上書きしない。送付先・金額・件名・住所は請求作成時のスナップショット。担当者を関連付けても、実宛先承認前はダミーアドレスを保持する。実宛先が承認された環境では、次回作成時に選択したCRM担当者のメールを参照する。

無効化は以後の月次作成・既存請求の送信を停止する。請求履歴と送信済みPDFを削除しない。同じ顧客・対象月の請求は再有効化しても二重作成しない。既にメール送信処理が開始したものの取り消しは行わない。

移行では、会社名が一意に完全一致する旧請求顧客だけを関連付ける。曖昧なものは未連携で残す。過去請求の宛名・金額は変更しない。

PDFは指定された見積書の紫色の上下帯、中央タイトル、3列明細、左下ロゴ、右下集計を再現した請求書。案内文を請求用へ変更し、支払期日・振込先・登録番号・請求番号を加えている。原本PDF全体は配布せず、ロゴだけを画像化して使用する。長い明細はページ分割する。
